# 你好，我是陈石 👋

**中文** · [English](README.en.md)

**商事律师 × AI Builder**

我是浙江海泰律师事务所副主任、高级合伙人，长期从事建筑房地产、投融资、并购及商事争议解决，也在写代码、做工具、分享 AI 实操经验。

这里的项目从真实工作出发：把法律分析与合同审核的方法做成 Agent Skill，把复杂材料整理成可追溯的输入，也做一些让资料、照片和个人网站更好用的小工具。我关心的是：**材料有没有读全，判断有没有依据，工具能不能用在日常工作里。**

[个人主页与文章](https://chenshi.ai/) · [桌面版主页](https://chenshi.ai/desktop) · [四明山法师 AI 夜校](https://legalagi.cn/) · [法律 Skill 聚合站](https://skill.chenshi.ai/)
